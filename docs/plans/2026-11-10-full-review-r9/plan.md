- **D79 — Fix policy and split rule.** P0 fixed in-session within at most **two files total** and 100 changed lines, one attempt; exceeding it or failing to reach green lands `LOOP OPEN`. Permitted shapes: one script or source file plus its regression test; or one non-behavior-changing file; or, for a wrong committed artifact, one data file plus the assertion that pins it.   - **Split threshold.** Split only when Phase 1 records **more than 120 distinct code anchors** or **three or more probe-dependent clusters**. A *distinct anchor* is one unique code `file:line` after de-duplication; prose `spec:line` units are prose rows, never anchors. Pre-scan (EV4) suggests a small surface (nine REQs across nine primary files), so a split is not expected — but step 7's count is the only authority.
- **D80 — Cross-chunk dedup.** Open findings from closed chunks are not re-filed: F-R7-G-1/G-2/G-3 (routing-citation coverage, renamed bare tools, README provider instruction), F-R7-A-1/A-2 (client-artifact gate strength), and F-R2-* spec-prose rows stay with their owners and are cited where relevant. A **new** violation of an R9-owned REQ gets its own ID, `F-R9-<cluster letter>-<n>`.
- **D81 — Evidence class.** Classify `_Check:_` first (worklist calibration rule 1). `REQ-055`, `REQ-077`, `REQ-078`, `REQ-080` are **G3**: verified through `validate-spec`, `check-gate-coverage`, `validate-readme`, and `check-gate-table`, not a unit test. `REQ-089` and `REQ-090` are **G0+G1**: the live advertised schema plus `src/tool-surface.test.ts`. `REQ-092` and `REQ-106` are **G1+G3**: a test plus a gate. `REQ-081` is **G1**: the Arena contract test plus live `inspect_providers`. Every predicate cell opens with its evidence class — `test:`, `gate:`, `static:`, or `live:`. A G1 clause supported only by a `static:` reading is a finding, not a `holds`.
- **D82 — No live probe harness.** R9 owns no runtime state: every REQ resolves to a gate, a test, or a file-presence artifact, and the only live surface (the advertised tool schema and the `inspect_providers` spec record) is already spawned over stdio by `src/tool-surface.test.ts` and `debate-club/src/mcp-contract.test.ts`.
